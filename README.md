# AI Chatbot GUI

A desktop chatbot application developed using Python and Tkinter. The chatbot provides an interactive graphical user interface and responds to user queries based on predefined patterns.

## Features

- Interactive GUI using Tkinter
- User-friendly chat window
- Real-time message exchange
- Supports programming-related queries
- Handles greetings and common questions
- Easy to customize and extend

## Technologies Used

- Python
- Tkinter
- Git
- GitHub

## How to Run

### Prerequisites

- Python 3.x installed

### Run the GUI Version

```bash
python GUI.py
```

### Run the Console Version

```bash
python chatbot.py
```
